## Important exclusion list

The research explicitly identifies several offers that are no longer dependable:

- DigitalOcean's retired Student Pack offer;
- GitHub Models, retired;
- Alibaba Qwen Code free tier, discontinued;
- discontinued standalone Anthropic student API credit;
- discontinued Cursor student discount;
- discontinued Windsurf student discount;
- Cloudflare student plan for US-only eligibility.

Do not design Neptune around these.

## Terms

All current quotas, prices, and eligibility values are snapshots. Verify them before activation.

The research itself warns that free-provider catalogs and student offers change rapidly.
