# Usage and Cost Accounting

## Accounting dimensions

```text
model
provider
task
agent
session
runtime
tool
resource
```

## Cost modes

### Mode A — $0 Backbone
Free model tiers, local support models, free compute/storage/deployment/monitoring and legitimate student benefits.

### Mode B — Minimal Paid Overflow
Small paid model/resource spend after free capacity is exhausted.

### Mode C — Burst Capital
Temporary cloud/model/GPU/startup credits used for high-value work.

The system must be able to return from Mode C to Mode A/B.

## Conceptual resource value

```text
capability × reliability × quota × duration
--------------------------------------------
cost
```

For temporary credits also account for:
- expiration urgency;
- replacement difficulty;
- migration cost.
