# Schemas

These JSON schemas are **draft representations**, not the complete Phase 0 source of truth.

The authoritative semantic definitions are:

1. core domain model;
2. component contracts;
3. architecture boundaries;
4. ADRs.

Schemas must remain consistent with those documents.

Do not expand schemas into a complete persistence model during Phase 0 merely because fields are easy to add.

Schema hardening belongs to the relevant implementation phase after the domain boundaries have been validated.
